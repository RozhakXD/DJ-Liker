# 🚀 DJ-Liker - Facebook Reaction Bot 🔥

![DJ-Liker Logo](https://github.com/user-attachments/assets/6203673b-c60f-4c82-a944-77cde9209660)

✨ Sebuah alat otomatis untuk mengirim reaksi ke postingan Facebook dengan memanfaatkan layanan bypass reCAPTCHA. Dibangun dengan Python dan `rich` untuk tampilan CLI yang elegan.

## 🌟 Fitur Utama

- ✅ 7 Jenis Reaksi Facebook (Like, Love, Care, Haha, Wow, Sad, Angry)
- ✅ Multi-platform support (Windows/Linux/macOS)
- ✅ Bypass reCAPTCHA v2 menggunakan API Multibot
- ✅ Antarmuka CLI interaktif dengan library `rich`

## 🛠️ Prasyarat

- Python 3.12+
- Akun [Multibot.in](https://multibot.in) dengan saldo mencukupi
- Cookies Facebook aktif

## 📥 Instalasi

```bash
$ apt update -y && apt upgrade -y
$ pkg install git python-pip
$ git clone https://github.com/RozhakLabs/DJ-Liker.git
$ cd "DJ-Liker"
$ pip install -r requirements.txt
$ python Run.py
```

## ⚠️ Catatan Penting

- ⏳ Interval 15 menit antara eksekusi (anti-ban system)
- 📛 Postingan harus dalam mode **PUBLIC**
- 💸 Pastikan saldo Multibot mencukupi
- 🔒 Gunakan akun **FAKE ACCOUNT** untuk menghindari risiko
